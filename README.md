# Tanya Sherstneva — Product Designer

English product design portfolio featuring Flowly and Atlas, plus selected design concepts.

## Publish with GitHub Pages

Create a public repository named exactly `USERNAME.github.io`, replacing `USERNAME` with your GitHub username in lowercase.
Upload the contents of this folder to the root of that repository. The local folder name does not need to change.
The root must contain `index.html`, `assets/`, `atlas/`, `flowly/`, and `.nojekyll`.

In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**, and save.
No build command, Node.js, or package installation is required.

The site address will be `https://USERNAME.github.io/`, with no project path.
The published address is shown in Settings → Pages. Leave Custom domain empty.

For updates, replace the changed files, preserving their paths, and commit to `main`.

## Contents

- `index.html`: portfolio homepage
- `flowly/index.html`: Flowly case study
- `atlas/index.html`: Atlas case study
- `flowly.html` and `atlas.html`: alternate case study URLs
- `assets/`: images used by these pages
- `assets/responsive/`: WebP images in multiple sizes; upload every included variant
- CSS and JavaScript files: styling and interactions

Google Fonts requires an internet connection. External profile and CV links are preserved from the local portfolio.
